# India-UPI-Spending-Behaviour-Analysis
15,900 raw UPI transactions → clean, analysis-ready data. Fixed 4 date formats, 5 currency formats, 76 hidden outliers, and 31 category typos. SQL (window functions, RANK, LAG) + Excel pivots + Power BI dashboard + Python — uncovering real spending behavior across 150 users, 10 cities.
